Open source / terminal / file manager

文件管理，
留在终端。

superfile 用多面板、当前目录搜索、预览和批量操作整理文件；Go 与 Bubble Tea 管理终端交互，文件操作作用于运行机器的文件系统。适合工程目录、SSH 远端和素材整理，也为本仓库的文件组织与交互设计提供参考。

它是什么？

终端里的文件管理器，类似“终端版资源管理器”。它管理文件与目录，不管理终端窗口或会话。

Upstream / actual footage

下方是原项目提供的实际操作录屏，能看到启动、双面板浏览和文件操作反馈；它不是本研究在这台电脑上的运行记录。

01 / Capabilities

从看见文件，到完成整理

这些是上游文档描述的能力；下方交互区展示操作方式与可见反馈。

01 / NAVIGATE

多面板浏览

并排打开目录，在路径之间切换，把常用位置固定在侧栏。

效果：减少来回切目录
02 / FIND

搜索与预览

动态筛选当前目录文件名，查看内容、元数据和图片预览。

效果：选中前先确认内容
03 / ORGANIZE

批量操作

选择多个条目，复制、剪切、粘贴或删除，查看进度与剪贴板。

效果：复杂整理可见、可控
04 / CUSTOMIZE

按习惯配置

更换主题、快捷键、编辑器，并开启元数据或 zoxide 等集成。

效果：适配终端工作流
02 / Interactive simulation

动手体验操作效果

先选中文件并点“复制”，再点另一个面板和“粘贴”。列表、预览、进度和剪贴板会随操作更新。

03 / How it works

一张图看能力、原理与效果

终端输入驱动界面状态；真实的 superfile 再通过 Go 调用本地文件系统。

01 / INPUT

键盘与鼠标

输入操作、切换焦点、搜索、选取文件和调整面板。

02 / STATE

Bubble Tea

模型接收消息并更新状态；Lip Gloss 组合终端画面。

03 / FILE SYSTEM

Go 文件接口

真实程序执行读目录、重命名、复制、移动等磁盘操作。

04 / FEEDBACK

预览与进度

预览、元数据和任务状态返回界面，让操作有反馈。

04 / Where it fits

适合哪些工作

以下场景由已核对功能推导，不代表本次运行测试。

工程目录整理

一侧看研究项目，另一侧看素材目录；复制文件、核对名称，再用编辑器处理内容。

远程终端维护

在服务器或 SSH 会话中浏览和管理文件，减少反复输入长路径。

素材预览与归档

查看图片和元数据、选择多项后批量处理；图像质量受终端支持影响。

对这个研究仓库的意义

它能帮助人工整理 projects/、sites/ 和图片素材，也提供一个研究终端交互架构的案例。来源、许可证、研究结论仍需逐项人工核对。

05 / Sources & limits

资料来源与边界

页面结合上游真实演示与公开资料制作。可点击的模拟界面不证明软件在本机的运行效果。

  • 原仓库 README、官方教程：功能、快捷键和平台说明。
  • 界面模型源码、文件操作源码：事件处理与本地文件操作。
  • 图像预览文档：Kitty 协议支持及 ANSI 降级；插件配置文档：外部工具集成方式。
  • 本站所用的官方动图来自原仓库 demo.gif。原仓库标注 MIT 许可证，未为动图单列许可；本站的能力图和交互模拟由本研究仓库制作。
使用前留意

上游 README 仍注明 Windows 尚未完全支持。高质量图片预览依赖终端协议；真实复制、删除等操作会修改磁盘，正式使用前应核对路径与选择项。本研究尚未实机验证。
