# Chippy Tea 网页重建：视觉核对

本次核对的目标是**测量 GitReverse 两份文字结果能够带来的首版网页效果**。生成页是一份可运行的实验产物；下文的 blocked 只表示它尚不能忠实复刻原网页。

## 比较对象与口径

- 原网页视觉依据：[桌面原站截图](../chippytea-source-desktop-comparison.png)、[手机原站截图](../chippytea-source-mobile-comparison.png)，来自 2026-09-26 的 Chippy Tea 官网，版权与品牌归其作者。
- 实做页：[网页入口](index.html)、[桌面截图](../chippytea-rebuild-desktop.png)、[手机截图](../chippytea-rebuild-mobile.png)。
- 同屏比较证据：[桌面并排图](../preview-chippytea-desktop-comparison.png)、[手机并排图](../preview-chippytea-mobile-comparison.png)。完整的原图和实做图均可单独打开，因此无需额外裁切局部图；首屏结构、按钮色、标识与应用预览都在同屏图中可见。
- 桌面：CSS 视口 1440×900，原图与实做图均为 1440×900 像素；手机：CSS 视口 390×844，两图均为 390×844 像素。Chrome 设备缩放均为 1，无密度换算。状态均为初始状态，无浏览器工具栏。
- 构建依据：[GitReverse 生成提示词](https://www.gitreverse.com/website/chippytea-com?url=https%3A%2F%2Fchippytea.com%2F)与[生成的 design.md](https://www.gitreverse.com/designs/chippytea-com)。原站截图只用于完成后的对照，没有放入实做页。

## Findings

- **[P1] 首屏结构与应用预览位置不符。** 原站桌面把文案与应用预览分成左右两栏，应用预览在首屏显著可见；实做页遵循生成说明的单列堆叠，预览从下一屏开始。用户第一眼看到的产品证据因此大幅减少。若要忠实复刻，应把首屏改成双栏并在右侧实现或引入授权的应用画面素材。
- **[P1] 品牌资产和主色遗漏。** 原站有黄色下载按钮、鱼形标识、胶带、手绘边框；实做页使用生成说明里的灰褐色、方角和低阴影。两者气质相关，但辨识度明显不同。若要忠实复刻，需要补充原站截图、资产与视觉标注，重新定义按钮和边框规则；不能用临时符号或伪造图案替代。
- **[P2] 手机首屏的内容顺序不同。** 原站手机画面中有音乐卡片与应用预览顶部，实做页在同样高度内仅进入下一节标题。需要补齐音乐模块并调整首屏间距与示意区顺序；生成文字未提供音乐素材。
- **[P2] 文案缺少技术与信任细节。** 原站首屏明确写 SwiftUI 与 Rust；实做页依据生成提示词只保留用途和人工审查，没有这两个技术名称。若目标是忠实介绍原产品，应对照原站补充，经人工确认后再发布。

## 五项视觉核对

| 维度 | 观察 |
| --- | --- |
| 字体与排版 | 生成说明建议 SF Pro Rounded，实做页在本地 Windows Chrome 使用可用的圆润系统字体回退；与原站的字形、字重和换行仍有差异。实做页英雄标题已按生成说明收敛到约 46px。 |
| 间距与布局 | 实做页有充足留白、方角和平面分隔，符合生成说明；原站桌面双栏、手绘应用预览与手机首屏密度均不同。 |
| 颜色 | 奶油色与深灰色方向相近；原站主要操作按钮是黄色，生成说明将其概括为灰褐色。实做页将文字灰褐色略加深以满足常规文字对比度。 |
| 图片与素材 | 原站鱼形标识、胶带、应用插图和音乐卡片在生成结果中未作为可用素材交付；实做页没有使用占位图、CSS 假画或拷贝原站截图充数。 |
| 文案内容 | 核心用途、人工审查、下载入口与空间统计已覆盖；部分技术信息、音乐与细节文案遗漏。 |

## 行为与可访问性

- 实做页的下载和源码链接指向从原站人工核对的公开地址。清理列表、Review 对话框、示意统计和 Activity 记录可操作；它们只修改浏览器里的虚构数据，不扫描或删除文件。
- 桌面 1440×900、手机 390×844 和窄屏 320px 均无横向溢出；浏览器无 JavaScript 页面报错。键盘可打开 Review、按 Escape 关闭，选项卡支持方向键切换。
- 灰褐色正文原推荐值在奶油色背景上约 4.30:1，本实验调整到约 4.98:1；主要小型按钮与导航触点设为至少 44px 高。
- 原站的 Clean up 操作在这次无头浏览器检查里没有产生可见的后续状态，因此不声称两边清理交互等价；这里只验证实做页自己的演示流程。

## 比较与修正记录

1. 初版实做页的标题达到约 82px，且主要按钮用了深灰填充；这与生成 design.md 的约 46px 标题及灰褐色 CTA 建议不符。已调整标题与按钮后重新捕捉[桌面](../chippytea-rebuild-desktop.png)和[手机](../chippytea-rebuild-mobile.png)画面。
2. 发现生成的灰褐色文字推荐值在奶油底上对比度约 4.30:1；已把文字用色调深，并扩大交互触点。更新后的同屏证据为[桌面](../preview-chippytea-desktop-comparison.png)和[手机](../preview-chippytea-mobile-comparison.png)。
3. 再次比较后，首屏结构、品牌资产和手机内容顺序仍有 P1/P2 差异。这些差异保留在实验首版中，以如实展示仅靠两份文字结果的效果。

## Implementation Checklist

1. 若目标改为高度还原原站，先取得可用的品牌资产与原网页各视口截图。
2. 用双栏桌面首屏、黄色下载按钮、手绘边框和手机内容顺序修正生成说明。
3. 继续按同视口截图对比，再逐项检查原站交互；不要把网页演示误当作 Mac App 功能。
