# Repository guidance

- Keep the root `README.md` concise: it is the project summary, ordered index, and short visual preview, not the full research report.
- Use `projects/NNN-short-name/` for each research project. Preserve assigned numbers and keep index rows in numeric order.
- Record source repository, attribution, license, actual findings, and image sources in each project's README. Add a real cover image with a descriptive caption to the root preview when a project is indexed. Do not invent project results or demo URLs.
- Keep an optional static demo in `sites/NNN-short-name/`; use relative asset paths and link it from the corresponding research entry when published.
- Treat `templates/subproject/` as a template, not as an indexed research project.
