# GitHub 优秀项目研究集

这是我研究优秀 GitHub 仓库的总项目。每个子项目记录原项目的价值、实现思路、亲自验证的结果与延伸实践；可交互的成果会在适合时提供独立网页。

> 这里是摘要与导航。完整研究内容放在各子项目目录中。所有原项目的代码、图片和名称仍归其作者及贡献者所有；引用和再使用请遵守对应项目的许可证。

## 仓库结构

```text
.
├─ README.md                    # 总览与有序索引
├─ projects/                    # 按 001、002、003… 编号的研究子项目
├─ sites/                       # 可选的静态网页展示
└─ templates/subproject/        # 新研究项目的起始模板
```

## 阅读与新增

从上方索引按顺序进入子项目。每份研究记录包含原仓库链接、研究动机、重点发现、验证过程、图片说明和许可信息。新增项目时，复制 [`templates/subproject/`](templates/subproject/README.md) 到 `projects/` 下的新编号目录，填写内容后在本页索引增加一行。

若有网页展示，建议放在 `sites/001-项目名/`，并在索引和子项目 README 中链接。将来可以通过 GitHub Actions 将 `sites/` 发布到 GitHub Pages；当前仓库尚未启用网页发布。
