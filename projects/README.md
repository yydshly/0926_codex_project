# 研究子项目

子项目以三位数字开头，例如 `001-example/`、`002-another-project/`。编号决定总 README 中的展示顺序；新增项目使用下一个编号，不重排已有编号。目录名的后半部分使用简短、稳定的英文小写名称和连字符。

每个目录至少包含 `README.md`。将封面和研究截图放在该目录的 `assets/` 中，并在 README 中说明图片内容与来源。研究中自行编写的示例可以留在子项目目录；独立静态网页放在根目录的 `sites/同编号同名称/` 中。

新项目从 [`../templates/subproject/`](../templates/subproject/README.md) 开始。完成后同步更新根目录 [`README.md`](../README.md) 的索引行。
