## V0.5 · 四种条件、三个种子的批量对照

2026-09-26，本机 Chromium 浏览器实际完成十二轮，每轮 24 秒，共 288 秒模拟时间。固定开阔场地、不规则运动、5 Hz、0.2 秒延迟，关闭测距扰动与丢包；四种条件各运行种子 42、43、44。每轮 481 个世界时刻、120 个已送达图像样本。

| 条件（各三轮） | A：发现 / 漏报 / 误报 | B：发现 / 漏报 / 误报 |
| --- | --- | --- |
| 明显光照变化 | 6 / 0 / 0 | 6 / 0 / 8 |
| 轻微光照变化 | 0 / 6 / 0 | 5 / 1 / 9 |
| 明显变化 + 图像噪声 ±24 | 6 / 0 / 0 | 0 / 6 / 3 |
| 恒定白昼 | 0 / 0 / 0 | 0 / 0 / 11 |
| **合计** | **12 / 6 / 0** | **11 / 7 / 31** |

A 为整体亮度规则，B 为变化像素比例规则。共 18 次预设光照事件，两种方法成功匹配事件的加权平均延迟均为 0.20 秒。结果只针对这些合成输入与固定规则，不能外推现实设备性能。

- [完整实验包](v05-full-batch.json)：页面实际导出的十二轮原始记录，格式 `illumination-batch/1`，可通过“导入批量实验包”打开。
- [汇总报告](v05-full-report.json)：格式 `illumination-batch-report/1`，包含总计、分条件和每轮结果，不含回放帧。导入实验包后根据保存统计重新计算，与该报告核对一致。
- [停止后的批次](v05-stopped-batch.json)：另一次四轮快速方案在第一轮完成后暂停并停止，实际保留一轮，状态为 `partial`。未完成轮次未保存、未计分。

固定批量方案版本为 `illumination-suite/1`，单轮规则仍为 `illumination-comparison/1`。四个种子 42 记录与下方 V0.4 对应实验逐帧一致。文件保存图像统计而非原始逐帧图像；导入校验结构与时序，不证明数据未被外部改写。使用步骤和验证范围见 [V0.5 说明](../WORKBENCH.md)。

## V0.4 · 两种方法的光照对照

以下四组均为本机浏览器实际运行一轮 24 秒后，从页面导出的原始实验和对照报告。共同条件：开阔场地、不规则运动、种子 42、5 Hz、0.2 秒延迟、关闭测距扰动与丢包。每组 481 个世界时刻、120 个送达图像样本。

| 条件 | A：发现 / 漏报 / 误报 | B：发现 / 漏报 / 误报 | 文件 |
| --- | --- | --- | --- |
| 明显光照变化 | 2 / 0 / 0 | 2 / 0 / 4 | [实验](v04-strong-run.json) · [报告](v04-strong-report.json) |
| 轻微光照变化 | 0 / 2 / 0 | 2 / 0 / 4 | [实验](v04-soft-run.json) · [报告](v04-soft-report.json) |
| 明显变化 + 图像噪声 ±24 | 2 / 0 / 0 | 0 / 2 / 1 | [实验](v04-noise-run.json) · [报告](v04-noise-report.json) |
| 恒定白昼 | 0 / 0 / 0 | 0 / 0 / 5 | [实验](v04-constant-run.json) · [报告](v04-constant-report.json) |

A 为整体亮度规则，B 为变化像素比例规则。成功匹配的报警平均延迟均为 0.20 秒；没有匹配事件时报告为 `null`。恒定光照没有预设光照事件。误报只针对光照任务，不表示像素变化统计有误。

实验格式为 `observation-lab/3`，可导入回放。报告格式为 `illumination-report/1`，保存固定评测版本 `illumination-comparison/1` 及各事件对应关系；报告不含完整实验帧，不能作为实验 JSON 导入。评价根据已保存的图像统计重新生成，不重新分析回放图像。具体计分和局限见 [V0.4 历史说明](../WORKBENCH-V04.md)。

## V0.3 · 图像观察

[`example-image-observation-v03.json`](example-image-observation-v03.json) 是本机浏览器实际运行“体验自动观察”一轮 24 秒后，通过页面导出的记录，格式为 `observation-lab/2`。

配置：开阔场地、不规则飞行、种子 42、明暗变化光照、5 Hz、0.2 秒延迟、关闭测距扰动和丢包。文件包含 481 个世界时刻、120 个已送达观测包，以及独立图像观察模块的统计。

| 事件送达时间 | 相机采样时间 | 图像统计结果 |
| --- | --- | --- |
| 4.20 s | 4.00 s | 亮度变化，约 94.45% 像素变化 |
| 8.20 s | 8.00 s | 亮度变化，约 94.45% 像素变化 |
| 14.40 s | 14.20 s | 画面变化，约 0.103% 像素变化 |
| 16.40 s | 16.20 s | 画面变化，约 0.103% 像素变化 |
| 18.60 s | 18.40 s | 画面变化，约 0.104% 像素变化 |
| 21.40 s | 21.20 s | 画面变化，约 0.103% 像素变化 |

这些事件不含物体类别或位置，也不能证明识别到了无人机。固定方向测距收到 6 个有效回波、114 个无回波；回波没有物体身份字段，不能把这两个统计直接当作识别结果。

可通过实验台“导入实验 JSON”打开文件，拖动时间条或点击事件复查。导入会校验格式、采样节奏和观测字段；图像统计采用文件保存值，不重新计算，也不验证文件内容是否被外部修改。不同浏览器或 GPU 的图像渲染结果可能存在差异。

## V0.2 · 遮挡与固定测距

`example-wall-42.json` 为 V0.2 实验台在本机浏览器实际运行一轮 24 秒后，通过页面“导出实验 JSON”得到的原始记录。

配置为中央遮挡墙、不规则飞行、种子 42、白昼、每秒 5 次采样、0.2 秒延迟、关闭测距扰动和丢包。数据中保留世界状态与观测包，两者用途不同：世界状态用于重绘和评估，观测包供数据解释。

文件格式为 `observation-lab/1`，V0.3 可导入回放，并明确显示旧记录没有图像观察统计。

这些数值属于未校准的合成场景，不能推断现实设备性能。两种格式均未在 JSON 中嵌入图像；回放时按记录的相机采样时刻重新渲染。
